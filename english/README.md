# 🤖 No-Code Agents Demo & Workshop — Gemini Enterprise

This repository collects the instructional materials, prompts, and fictional data kits for demo sessions and hands-on workshops on **Gemini Enterprise (Agent Designer & Workflow Builder)**.

The repository is organized into two main sections:

```text
english/
├── kitchen-brigade/ <- Guided demo case ("Kitchen Brigade": Chat Agent + Workflow)
└── use-cases/       <- 9 business use cases for the hands-on workshop ("Build Your Own Agent")
```

---

## 🍽️ 1. Guided Demo Case: Kitchen Brigade (`kitchen-brigade/`)

A guided culinary metaphor designed to demonstrate in plenary sessions the architectural difference between a **Conversational Multi-Agent System** (Head Chef Orchestrator + Station Chefs) and a **Sequential Operational Workflow** (shopping list, allergens, food cost, and *mise en place*).

- 👉 **[Go to the guided demo overview (`kitchen-brigade/README.md`)](./kitchen-brigade/README.md)**
  - 💬 [Part 1 · Chat Agent (`kitchen-brigade/chatagent/README.md`)](./kitchen-brigade/chatagent/README.md)
  - ⚙️ [Part 2 · No-Code Workflow (`kitchen-brigade/workflow/README.md`)](./kitchen-brigade/workflow/README.md)
