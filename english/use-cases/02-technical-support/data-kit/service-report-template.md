# Technical Service Report Template (L2 Escalation)

Use the exact structure below for all escalation requests to Level 2 (L2) technical support.
**Completion rule:** If a piece of information is missing from the incoming report, write `to be completed`. Never invent data or spare part codes.

---

## L2 TECHNICAL SERVICE REPORT

- **Customer:** `[insert customer name or "to be completed"]`
- **Machine Serial Number:** `[insert serial number e.g. M-0042 or "to be completed"]`
- **Alarm Code / Symptom:** `[insert code e.g. E104 / S-01]`
- **Problem Description:** `[technical summary of the reported issue]`
- **Assigned Priority:** `[HIGH / MEDIUM / LOW + brief rationale]`
- **Escalation Reason:** `[state whether: alarm not documented in manual / required by manual / recurrence > 2 times on the same serial number]`
- **Level 1 Checks (to be performed / already performed):** `[list the steps specified in the manual or "to be completed"]`
- **Previous Occurrences on This Serial Number:** `[report number of occurrences and ticket IDs from history]`
- **Suspected Spare Parts:** `[list only spare parts with codes explicitly cited in the manual or ticket history, otherwise "none / to be verified"]`
